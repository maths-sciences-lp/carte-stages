# Trouve ton stage

Carte des entreprises d'Île-de-France pour la recherche de stage des élèves de CAP et de bac pro : choisir sa formation (ou un domaine), indiquer d'où l'on part (chez soi ou son lycée), voir les entreprises les plus proches.

En ligne : https://maths-sciences-lp.github.io/carte-stages/

Données : répertoire Sirene de l'Insee via l'API Recherche d'entreprises (5 octobre 2026, Licence Ouverte 2.0) ; formations : ministère de l'Éducation nationale et Onisep ; lycées : annuaire de l'éducation ; adresses : Base Adresse Nationale ; fond de carte © contributeurs OpenStreetMap.
