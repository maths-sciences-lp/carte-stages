# Entreprises pour les stages

Carte des entreprises de Paris et de Seine-Saint-Denis dans les métiers de l'énergie (chauffage, climatisation), de la menuiserie et de l'agencement, de l'ébénisterie, de la signalétique, du géomètre et des études du bâtiment.

En ligne : https://maths-sciences-lp.github.io/carte-stages/

Données : base Sirene de l'Insee, via l'API Recherche d'entreprises, 5 octobre 2026, Licence Ouverte 2.0. Recherche d'adresse : Base Adresse Nationale. Fond de carte © contributeurs OpenStreetMap.
